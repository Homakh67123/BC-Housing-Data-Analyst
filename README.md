# BC-Housing-Data-Analyst
BC Housing data analytics project using Excel, Power Query, and Power BI. Includes three dashboards: Executive Summary, Cluster Analysis, and Trends, showcasing data cleaning, transformation, interactive visualisation, and trend analysis to uncover insights and support data-driven decision-making.

BC Housing Data Analytics Project

Project Overview

This project explores BC Housing data using Microsoft Excel, Power Query, and Power BI. The workflow involved preparing and transforming data, analysing key metrics, and developing three interactive dashboards to present insights clearly and support data-driven decision-making.

Tools & Technologies

- Microsoft Excel: Data review, preparation, and initial analysis.
- Power Query: Data cleaning, transformation, and preparation for reporting.
- Power BI: Data visualisation, dashboard development, and interactive analysis.

Dashboard 1: Executive Summary

Provides a high-level overview of the BC Housing data through key performance indicators (KPIs) and summary visualisations. It helps users understand the overall picture, identify important findings, and quickly review the main housing metrics.

Key objectives:

- Summarise key housing indicators.
- Present important metrics in an accessible format.
- Support quick, high-level decision-making.

Dashboard 2: Cluster Analysis

Focuses on identifying patterns and similarities within the housing data by grouping relevant data points into clusters. This view helps users explore differences between groups and understand the characteristics of different segments.

Key objectives:

- Explore patterns and relationships within the data.
- Compare groups or segments.
- Identify similarities and differences across clusters.

Dashboard 3: Trends Analysis

Examines changes and patterns in the data over time, helping users understand how key housing metrics evolve. The visualisations make it easier to identify upward or downward movements and potential areas requiring further investigation.

Key objectives:

- Analyse changes over time.
- Highlight trends and recurring patterns.
- Support evidence-based interpretation of housing data.

Project Workflow

1. Reviewed and prepared the source data in Excel.
2. Cleaned and transformed the data using Power Query.
3. Built interactive dashboards in Power BI.
4. Presented the analysis through Executive Summary, Cluster Analysis, and Trends dashboards.

Key Skills Demonstrated

Data Preparation | Data Cleaning | Power Query | Excel | Power BI | Data Visualisation | Exploratory Data Analysis | Dashboard Development
